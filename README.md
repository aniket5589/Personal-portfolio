# Personal Portfolio Website

A modern, responsive personal portfolio website created for Web Development Internship Task 1.

## About the Project
This project is a static, frontend-only portfolio website designed to showcase education, skills, experience, and projects. It is built focusing on clean design, responsiveness, and clean code architecture without relying on external frameworks.

## Features
- **Responsive Design**: Works perfectly across mobile, tablet, and desktop devices.
- **Modern UI**: Dark-themed aesthetic with a clean layout and readable typography.
- **Smooth Animations**: Includes scroll reveal animations and smooth scrolling.
- **Frontend Form Validation**: Client-side validation for the contact form with immediate user feedback.
- **Semantic HTML**: Structurally sound HTML5 layout.

## Technologies Used
- HTML5
- CSS3 (Flexbox, Grid, CSS Variables)
- Vanilla JavaScript (ES6)

## Project Structure
```text
portfolio/
├── index.html     # Main HTML document
├── style.css      # Stylesheet containing all CSS
├── script.js      # JavaScript for interactions and form validation
├── README.md      # Project documentation
└── assets/        # Directory for images and other media
    └── profile.jpg # Profile image
```

## How to Run Locally
1. Clone or download this repository to your local machine.
2. Ensure you have the `assets/profile.jpg` file in the correct directory.
3. Open `index.html` in any modern web browser. No local server or build tools are required.

## How to Replace/Update the Profile Image
1. Navigate to the `assets` folder.
2. Replace `profile.jpg` with your own image.
3. Ensure the image is named exactly `profile.jpg`.
4. The CSS will automatically handle resizing and displaying it correctly.
